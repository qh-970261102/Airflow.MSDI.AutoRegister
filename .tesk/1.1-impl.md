# 1.1 错误检测规划

> 本文档为 **1.1 版本**的 Diagnostic 实现规划。
> 1.0 版本**不做任何 error 检测**:所有非法形态都会被生成器静默跳过。
> 本文档逐条列出 1.1 需要检测的条件、严重级别与建议修复方式,供后续实现直接参照。

## 通用规则

- 所有 Diagnostic 使用 `AMAR` 前缀 + 4 位数字编号(`AMAR1001` …)。
- 生成器通过 `SourceProductionContext.ReportDiagnostic` 输出。
- Error 级 Diagnostic 会阻止编译成功(生成器不产出对应代码);Warning 级仅提示。
- 每条 Diagnostic 都应给出:触发条件、定位(Location)、消息文案(建议中英双语)、修复建议。

## 1. 工厂方法相关(核心)

| ID | Severity | 触发条件 | 建议 |
|---|---|---|---|
| `AMAR1001` | Error | 拥有工厂方法的类**不是普通类**(`abstract` / `static` / `interface` / `struct` / 泛型类) | 工厂方法拥有类必须是可实例化的普通类,消息中给出类名 |
| `AMAR1002` | Error | 拥有工厂方法的类**自身又带有注册特性** | 拥有类会被自动注册为单例,不能再添加注册特性;提示移除类上的特性 |
| `AMAR1003` | Error | 工厂方法是 `static` | 工厂方法必须是实例方法(需要通过拥有类单例解析) |
| `AMAR1004` | Error | 工厂方法不是 `public` | 生成代码需要跨类访问,方法必须 public |
| `AMAR1005` | Error | 工厂方法是泛型方法 | 1.0/1.1 不支持泛型工厂方法 |
| `AMAR1006` | Error | 工厂方法返回 `void` | 返回值类型即服务类型,不能为 void |
| `AMAR1007` | Error | 工厂方法返回类型是泛型/不可解析类型 | 返回值必须是非泛型具名类型 |
| `AMAR1008` | Error | 工厂方法参数不是"无参或仅一个 `IServiceProvider`" | 只支持无参或单个 `IServiceProvider` 参数;提示删除参数或改为 `IServiceProvider` |
| `AMAR1009` | Error | 工厂方法参数只有一个但不是 `IServiceProvider`(如 `string`、其他服务类型) | 参数必须是 `System.IServiceProvider` |
| `AMAR1010` | Error | `[SingletonService]` 工厂方法带 `IServiceProvider` 参数 | 单例工厂只允许无参;单例方法的依赖应来自拥有类构造注入,不需要 `sp`。若确实需要解析 scoped 依赖,说明生命周期用错了 |

## 2. 类注册相关

| ID | Severity | 触发条件 | 建议 |
|---|---|---|---|
| `AMAR2001` | Error | 注册特性作用于**不支持的目标**(字段、属性、局部函数等) | 注册特性只允许用于类与方法(AttributeUsage 已约束,此项多为防御) |
| `AMAR2002` | Error | 注册特性的服务类型参数不是接口/类(如传了泛型参数、数组、指针) | 服务类型必须是具名类型 |
| `AMAR2003` | Error | 类本身是泛型(未闭合)却带注册特性 | 1.x 不支持开放泛型注册;提示闭合泛型或使用手动注册 |
| `AMAR2004` | Error | 实现类型不可访问(如 `private` 嵌套类、`internal` 而生成代码所在程序集不同) | 服务实现必须对生成代码可访问 |
| `AMAR2005` | Warning | 同一 `(ServiceType, ImplType)` 重复注册(同一类重复特性,或多类同服务类型同 Order) | 提示重复注册,后注册者胜出,确认是否有意 |
| `AMAR2006` | Warning | 类同时有自身注册与接口注册,但生命周期**不一致**(如自身 Singleton、接口 Scoped) | 同实例规则下建议生命周期一致;不一致时按各特性自身生命周期注册 |

## 3. AutoRegister 方法相关

| ID | Severity | 触发条件 | 建议 |
|---|---|---|---|
| `AMAR3001` | Error | `[AutoRegister]` 方法**不是 partial 方法** | 必须声明为 `partial`,生成器才能补全实现 |
| `AMAR3002` | Error | `[AutoRegister]` 方法所在类**不是 partial 类** | 类必须 `partial`,生成器才能合并 |
| `AMAR3003` | Error | `[AutoRegister]` 方法已存在实现部分(用户手写了方法体) | 移除手写实现,由生成器生成 |
| `AMAR3004` | Error | `[AutoRegister]` 方法不是 `static` | 注册方法必须是静态方法 |
| `AMAR3005` | Error | `[AutoRegister]` 方法参数不是单个 `IServiceCollection` | 签名必须是 `(IServiceCollection services)` |
| `AMAR3006` | Warning | 程序集内没有任何带注册特性的类/方法 | 提示没有可注册的服务,检查特性是否拼写错误 |

## 4. 特性元数据相关

| ID | Severity | 触发条件 | 建议 |
|---|---|---|---|
| `AMAR4001` | Error | `BaseServiceAttribute` 子类**缺少 `[RegistrationOptions]`** | 所有子类特性必须用 `[RegistrationOptions]` 描述元数据(需求 1.0 第 2 条) |
| `AMAR4002` | Error | `RegistrationOptions` 的 `LifetimeIndex` / `ServiceTypeIndex` / `OrderIndex` 超出构造函数参数个数 | 索引与构造函数签名不匹配 |
| `AMAR4003` | Error | 构造参数索引对应的**类型不符**(如 `ServiceTypeIndex` 指向非 `Type` 参数) | 检查 `RegistrationOptions` 索引是否正确 |
| `AMAR4004` | Error | `RegistrationOptions` 中生命周期枚举值非法(不是 Singleton/Scoped/Transient) | 只支持 MSDI 三种生命周期 |
| `AMAR4005` | Warning | 自定义特性继承链上存在**多个** `[RegistrationOptions]` | 只取最近的;提示移除冗余 |

## 5. 未来扩展(非 1.1 承诺,仅备忘)

- `AMAR5001` 增量生成器缓存优化后,输出 hintName 稳定性保证。
- 开放泛型注册(`AddSingleton(typeof(IOpen<>), typeof(OpenImpl<>))`)支持评估。
- Keyed services(需要 MSDI 6.0+,与"仅 MSDI 1.0 API 面"的约束冲突,默认不做)。

## 实现要点

1. 1.0 中"静默跳过"的每个 `return` 分支,在 1.1 都对应上述一条 Diagnostic,替换为"ReportDiagnostic + return"。
2. 建议为每条 Diagnostic 写单元测试(触发 → 断言 Diagnostic 存在、消息含类型名、生成代码不含对应注册)。
3. `RegistrationOptions` 解析失败时,`ReadOptions` 目前返回全默认值;1.1 应在缺失 `[RegistrationOptions]` 时直接报 `AMAR4001` 而非静默用默认值。
